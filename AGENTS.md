# Project requirements

Preserve the current website layout, navigation shell, card/table structure and visual style unless the user explicitly requests a layout change. This product is for site monitoring and progress; do not introduce monetary claims, valuations or cashflow features. Display recorded/confirmed project data, never fabricated site readings or seeded operational records.

The user has authorized visual layout improvements while preserving all existing product functions. Target WCAG 2.2 AA through labels, contrast, focus management, keyboard access and responsive layouts. Deletion policy: admins delete directly; other creators request deletion with independent admin/manager verification.
